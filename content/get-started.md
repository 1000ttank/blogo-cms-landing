> Blogo CMS 是基于 Next.js + GitHub API 的 Hexo 博客内容管理系统，采用 Git 驱动、无服务器架构。

### Hexo 部署

如果您没有 Hexo 博客，请看 [**部署 Hexo 博客**](/deploy-blog/) 章节。

### CMS 部署

CMS 目前支持以下部署方案：

- [**本地部署**](/deploy-cms-local/)：可以直接在您的系统上运行 CMS，使用 localhost 进行访问；
- [**Github Pages 部署**](/deploy-cms-github-pages/)：最便捷快速的部署方案，无服务器费用；
- [**Docker 部署**](/deploy-cms-docker/)：在本地使用 Docker 进行部署，更方便的进行扩展操作。
